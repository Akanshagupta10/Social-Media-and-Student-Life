# Social-Media-and-Student-Life
Data Analytics practice projects social media and student life

Power BI Data Analytics Mini Project

1. Overview
This project explores the relationship between social media usage and students' academic performance, mental health, sleep habits, and personal relationships. The Power BI report is designed to turn student-related data into clear, interactive insights.
The project follows an end-to-end analytics workflow: reviewing and preparing data, building interactive dashboards, documenting findings, and presenting the results.

3. Dataset
The Power BI model contains three tables:
- Student Details — student demographics, academic level, social media addiction score, sleep hours, mental health score, relationship status, and conflicts over social media.
- Platform Details — social media platform usage, average daily usage hours, and whether social media affects academic performance.
- Date Table — a date table included in the data model.
The report uses fields such as age, gender, country, academic level, most-used platform, addiction score, sleep hours, and mental health score.

5. Dashboard Pages
Page	Focus
Executive Overview	Average sleep hours, average usage hours, academic impact, addiction score by academic level, usage by age, and gender distribution.
Mental Health & Lifestyle	Country and health-band comparison, addiction score versus mental health score, and sleep hours by age. Includes a gender slicer.
Academic Impact	Average usage hours by academic level and academic impact by most-used platform. Includes an age slicer.
Relationships & Conflicts	Student counts by relationship status and conflict level, relationship-status distribution, and addiction score comparison. Includes country and academic-level slicers.
Interactive Story View	Comparisons of usage hours by gender and academic level, plus distribution of students by most-used platform.
Student Profile	Student-level details and indicators such as sleep hours, daily usage, addiction score, most-used platform, conflicts, and mental health score.
